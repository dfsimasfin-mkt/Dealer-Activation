Firebase belum terhubung

Terjadi kegagalan koneksi ke Firebase. Cek console browser (F12) untuk detail error, dan pastikan domain ini sudah ditambahkan ke Authorized Domains di Firebase Console.

Lihat SETUP-FIREBASE.md untuk langkah lengkap: membuat project, mengaktifkan Firestore + Authentication, deploy Security Rules, dan menambahkan domain GitHub Pages ke Authorized Domains.
